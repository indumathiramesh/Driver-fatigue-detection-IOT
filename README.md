# A Low-Latency IoT Framework for Real-Time Driver Fatigue Detection Using YOLO and Multi-Level Safety Alerts

## Project Overview

Driver fatigue is a major cause of road accidents, particularly during long-distance driving. This project develops a real-time IoT-based driver fatigue detection system using a camera and a YOLO-based deep learning model to identify fatigue indicators such as eye closure and head movement.

An ESP8266 microcontroller manages the alert system and provides multi-level warnings through a buzzer, vibration motor, LCD and LEDs. The system also supports remote monitoring through IoT communication and email notifications.

## Objectives

- Detect driver fatigue at an early stage.
- Provide real-time fatigue detection with low latency.
- Implement multi-level safety alerts.
- Provide remote notifications during fatigue events.
- Develop an affordable and practical driver safety system.

## Working Principle

1. The camera continuously captures the driver's facial images.
2. The YOLO-based model processes the images.
3. Fatigue indicators such as eye closure and head drooping are detected.
4. Detection results are communicated to the ESP8266.
5. The ESP8266 activates the appropriate safety alert.
6. Alerts are provided through the buzzer, vibration motor, LCD and LEDs.
7. Remote notifications are sent through the IoT communication system.

## Key Features

- Real-time driver fatigue detection
- YOLO-based deep learning
- Eye closure and head movement detection
- Low-latency communication
- Multi-level safety alerts
- IoT-based remote monitoring
- Email notifications
- Captured-image notifications

## Results

The system successfully performed real-time driver fatigue detection and provided multi-level safety alerts. The IoT functionality also enabled remote email notifications during fatigue events.
